# 会话式视频工作台

## 规则

| 当 | 则 |
| --- | --- |
| 进入原型 | 显示会话侧栏、中性内容流和底部输入器 |
| 切换会话 | 立即展示该会话状态；其他会话中的本地任务继续推进 |
| 新建会话 | 回到空状态，保留创建输入器 |
| 创建阶段选择口播转换 | 保持原文、改写或翻译作为分析输入；翻译时同时选目标语言 |
| 提交链接或文件 | 创建本地 mock 会话，模拟排队、处理和完成 |
| 分析完成后选择 H3 参数 | 台词 `auto/edit/custom/none` 与画幅、清晰度、适配方式一起冻结 |
| 发起关键帧后处理 | 在分析结果的确认弹窗中选去字幕水印/去版权物品，然后模拟运行与完成 |
| 后处理运行时关闭弹窗 | 任务转到后台继续推进，可切换会话后再返回查看 |
| 生成完成 | 显示成片，并继续回显已冻结的全部生成参数 |

## 边界

- 未选文件、未填链接或未选合法生成参数时，提交按钮不可用。
- 链接和上传文件使用独立状态，切换来源不会让文件名冒充链接。
- 本地运行中的操作按钮不可重复触发。
- 移动窄屏中侧栏收入 Drawer，不遮挡底部输入器。

## 例子

- 输入一个视频链接并选择“原文保持” → 创建一个新会话，几秒后展示关键帧与生成入口。
- 选择 `16:9 / 768p / 裁切` 并确认 → 页面显示冻结参数，分片从等待进入完成。
