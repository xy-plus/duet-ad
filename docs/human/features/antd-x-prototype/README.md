# Ant Design X 无后端原型

## 要什么

产品与开发可在不连接生产服务的前提下，体验一套使用 Ant Design 与 Ant Design X 重建的会话式视频工作台。

## 为什么

先用可操作原型验证 ChatGPT 类布局、组件选型和状态呈现，再决定是否替换现有前端，避免直接触及真实付费生成链路。

## 验收

- [x] 可新建、切换会话，并在桌面和移动布局中使用。
- [x] 创建时可在链接/上传与原文保持/改写/翻译间切换，提交后本地模拟分析进度。
- [x] 可查看关键帧、提示词、台词、生成参数和长视频分片。
- [x] 分析后可分别设置 H3 的 `auto/edit/custom/none` 台词模式和画幅参数，并可对关键帧启动本地后处理。
- [x] 可本地模拟 H3 分片生成，完成后继续回显已锁定的台词、画幅、清晰度和适配参数。
- [x] 实现不发起任何 duet-ad1 后端或 provider 请求。

## 边界

- 原型数据只存在浏览器内存，刷新后恢复预置状态。
- 不替换现有 `web/`，不修改 FastAPI 路由，不触及真实媒体或付费接口。
- 视频和关键帧使用内置演示占位素材，只验证交互与视觉层级。

## 取舍

- 只使用 Ant Design 与 Ant Design X 作为视觉体系；不引入另一套聊天 runtime 或组件库。
- 保留成片结果区域，但使用本地占位卡，不嵌入大体积演示视频。

> 表现规格见 `behaviors/workbench.md`。
