# 会话式视频复刻任务

## 要什么

给运营/创作者一个 ChatGPT 式单页界面：一次会话 = 一支参考视频（任意类别）的复刻任务。上传视频（可附备注）后，系统自动产出可评审的 Seedance 2.0 素材包——≤9 张有序关键帧与提示词；评审满意后预留一键提交 Seedance 生成最终视频（当前阶段默认未开放）。

## 为什么

人工看片选帧、写 Seedance prompt 慢且质量不可复现；`skills/video-maker` 已把方法论固化成技能，现在需要把它产品化为低门槛、可自助的 Web 工具，并让 agent 在沙箱里跑，密钥与宿主环境不出服务进程。

## 验收

- [x] 口令登录后进入会话界面，侧栏列出历史会话（含状态徽章）
- [x] 选择视频 + 可选备注发送后，会话进入排队/处理中，界面每 2 秒自动刷新状态
- [x] 完成后看到关键帧网格、可一键复制的 Seedance prompt，最终视频区显示「待提交生成」
- [x] 失败会话展示可读的错误原因，不暴露内部路径/环境信息
- [x] 「生成最终视频」按钮可见但禁用，标注预留未开放；开启后必须二次确认且防重复提交
- [x] 非法上传（类型/大小/时长超标）被拒绝且不残留会话记录

## 边界

- 不做账号体系：全站一个共享访问口令，无用户/权限概念
- 当前阶段不真实提交 Seedance（接口预留，默认 501）；不再生成占位预览，最终视频区只显示「待提交生成」
- 不处理含明显第三方人物/商标/版权元素的素材（发现即应换干净源片）
- 状态推送用轮询（2s），不上 SSE/WebSocket；单进程内存态，重启丢限流/锁状态
- 不保证处理时长：codex 硬超时 10 分钟，超时即失败

## 取舍（可选）

- 本地沙箱 codex agent，而非云端 API：素材不出机器、复用已验证的 skill；代价是单机串行（默认并发 1）
- 关键帧 + prompt 先行，真实生成后置：先让人评审产物，避免为烂 prompt 付生成费
- 单口令 + 公网暴露：够用且简单；代价是口令即全部防线（见 docs/agent 安全模型）
