# 结果评审与 H3 参数

## 规则

| 当 | 则 |
| --- | --- |
| 输入准备为 `done` | 展示源视频、每段 3 张原始关键帧、每段 3 张优化关键帧和最终 H3 prompt；图片确认、台词、声音呈现、画幅、清晰度和适配方式位于同一生成流程 |
| 任一当前 v4 项目 H3 attempt 尚未创建 | 按统一 segment 工作区展示提示词；保存使用当前 SHA-256 防止覆盖新版本，`N=1` 不切换另一套界面或 API |
| H3 attempt 已创建 | H3 源提示词锁定；不能让页面展示内容与已冻结输入发生漂移 |
| 选择 `auto` | 使用详情 `dialogue.auto_lines` 中的自动有效台词，不允许随请求上传 `lines` |
| 选择 `edit` | 以自动台词预填，提交至少一行 `{text,start_s,end_s}` |
| 选择 `custom` | 提交至少一行人工台词，不依赖自动识别结果 |
| 选择 `none` | 发声块明确写“无台词”，不允许上传 `lines` |
| 用户确认生成参数 | 请求显式提交台词、`16:9/9:16` 画幅、`480p/768p` 清晰度和适配方式；H3 源提示词直接作为实际生成输入 |
| 生成确认 | 展示 `segments.length` 和冻结的付费子任务数量；所有项目提交时绑定当前 plan receipt |
| 生成中 | 使用同一组件展示各段的 chain、join、状态和 attempt；`N=1` 只显示一个 segment，不公开供应商 task id |
| 准备完成 | 服务端在 `16:9/9:16` 中选真实 H3 输入几何损失较小者；平局按源视频方向、仍平局取 `9:16`。清晰度按源视频短边距 `480/768` 最近者，平局取 `480p` |
| 用户改变画幅 | 页面只读取该画幅的服务端 `fit_profiles`：全部实际 H3 输入帧完全匹配时固定 `none`，否则显示 `crop/pad` 且默认 `crop` |
| generation active | 禁用参数和提交按钮，2 秒轮询状态 |
| 其他标签页已经提交或当前 generation 已冻结 | 丢弃本页尚未提交的参数草稿，始终显示并锁定服务端冻结的画幅、清晰度、台词与适配方式；失败重试也不能显示另一套草稿参数 |
| generation 为 `resume_required` | 台词、画幅和请求 id 锁定，显示“继续既有任务”；确认后继续原 attempt |
| 任一 segment 为已确认 `h3_provider_failed` | 保持真实失败状态；成功兄弟不重提，`N=1` 与 `N>1` 行为相同；只有用户点击“重试生成”才创建新请求 id |
| H3 阶段其他确定失败 | 展示错误、“重试生成”和服务端给出的本次新增付费子任务数；点击才创建新请求 id |
| 本地拼接失败 | 即使已有可播放的半发布成片，也同时展示成片和恢复区；“重试拼接”显示新增 0 个付费 H3 子任务，复用原请求 id，只执行统一拼接器；`N=1` 输入列表长度为一 |
| generation 为 `submission_unknown` | 展示“先到供应商核对”的阻断说明，不显示重试按钮 |
| `generated.mp4` 存在 | 同时内嵌播放原视频和 H3 最终视频，并用详情中的冻结值只读展示画幅、清晰度、台词模式、声音呈现、适配方式、实际总时长和 segment 数 |
| 旧会话 | 展示只读提示；不能修改台词、画幅、后处理或再次生成 |

## 边界

- `duration_s` 展示实际 ffprobe 时长；上传门禁确保其不超过总输入上限 300 秒。
- 所有媒体经带 Bearer 鉴权的 files API 获取，页面使用 blob URL，不暴露目录直链。
- 画面 OCR 只在视觉 prompt 中展示；唯一发声块只由结构化台词机械生成。
