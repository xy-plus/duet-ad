# 长视频分段生成

## 规则

| 当 | 则 |
| --- | --- |
| 源视频不超过 10 秒 | 保持现有单个 H3 多图参考任务，不改变已有结果与付费语义 |
| 源视频超过 10 秒且不超过 300 秒 | 按场景规划连续片段，每段 1–15 秒，并在确认页显示子任务数量 |
| 查看分段产物 | 每段提示词默认折叠并可反复展开；关键帧默认显示小缩略图，可点击或用 Enter/Space 查看大图，关闭后回到缩略状态 |
| 两段属于同一镜头 | 下一段使用上一段生成尾帧作为首帧，并使用当前源片段末帧作为目标尾帧 |
| 边界是硬切 | 新片段从源视频首帧与末帧独立起链，不继承上一镜头尾帧 |
| 同时存在多条硬切链 | 同一链严格串行；不同链最多同时推进两条 |
| 长视频选择自动台词 | H3 分段音轨不进入成片；成片复用源音轨，长于画面时裁剪、短于画面时补静音，画面时长不变 |
| 长视频选择无台词 | H3 分段音轨不进入成片，最终输出静音视频 |
| 长视频确认画幅 | 检查 plan 绑定的硬切 first 与全部 end anchors；续接 first 运行时使用上游尾帧，不按 source first 判断 |
| 长视频开始或继续生成 | 所有 segment 共用已冻结的画幅、清晰度和适配方式；续接段的上游尾帧也按同一目标画幅处理 |
| H3 阶段某段确定失败 | 用户确认“重试生成”后使用新请求 id；服务端只复用状态成功且成片文件仍存在的段，并给出本次新增付费任务数 |
| 全部分段成功但本地拼接失败 | 即使会话级成片已半发布，仍展示成片与恢复区；用户确认“重试拼接”后复用原请求 id 和冻结输入，只在本地重拼；本次新增付费 H3 子任务为 0 |
| 某段提交结果未知 | 停止后续新提交并锁定整批，先去供应商核对，不允许自动或人工重提 |
| 全部分段成功 | 归一化后按顺序拼接，校验总时长并原子写入会话级 `generated.mp4` |

## 边界

- 超过 300 秒、无法形成合法片段或台词跨越安全边界时，在任何付费请求前失败。
- 一期长视频不支持改写、翻译、编辑或自定义台词；这些模式返回明确错误，不静默降级。
- 拼接失败只重做本地拼接，不重新提交 H3。
- 首尾帧和连续性提示词只能提高连贯性，不承诺无缝或人物绝对一致；该链路不是供应商原生 extend。

## 例子

- 输入：15 秒同镜头视频 → 输出：1 个 FL2VA 子任务和约 15 秒成片。
- 输入：30 秒、两个连续 15 秒片段 → 输出：2 个按链顺序生成的 FL2VA 子任务和约 30 秒成片。
