# 长视频分段生成

## 规则

| 当 | 则 |
| --- | --- |
| 新源视频不超过 15 秒 | 使用单个多图参考生成任务 |
| 新源视频超过 15 秒且不超过 300 秒 | 按场景规划连续片段，每段 provider 整秒时长不超过 14 秒，并在确认页显示子任务数量 |
| 查看分段产物 | 每段提示词默认折叠并可反复展开；关键帧默认显示小缩略图，可点击或用 Enter/Space 查看大图，关闭后回到缩略状态 |
| 两段属于同一镜头 | 两段都使用各自 1–9 张多图参考；`continue` 用于连续性提示词、调度和拼接边界 |
| 边界是硬切 | 新片段仍使用自身多图参考，并开始新的 chain |
| 当前网页新建长视频 | 固定开启“快速模式”，确认页不显示开关或说明，结果参数摘要也不展示该模式；先冻结所有分段的多图参考输入，再快速提交各段。供应商仍可能排队，不代表其 GPU 同时生成 |
| 兼容调用显式提交 `fast_mode=false` | 保持串行生成顺序：同一链等待上一段完成后再提交下一段；同时存在多条硬切链时最多推进两条 |
| 已经创建 generation | “快速模式”以服务端冻结值为准；继续、失败重试和本地拼接重试均复用原选择，历史任务缺失该值时按关闭处理 |
| 长视频选择自动台词 | H3 分段音轨不进入成片；成片复用源音轨，长于画面时裁剪、短于画面时补静音，画面时长不变 |
| 长视频选择无台词 | H3 分段音轨不进入成片，最终输出静音视频 |
| 长视频确认画幅 | 检查 plan 绑定的各段关键帧；优化完成时以 `postprocessed/` 为准，随后统一派生所选画幅 |
| 长视频开始或继续生成 | 所有 segment 共用已冻结的画幅、清晰度和适配方式；每段只读取自身已冻结的多图参考 bytes |
| 某段供应商明确返回 `FAILED/ERROR/FAIL` | 完整持久化为 `h3_provider_failed` 后，服务端按固定间隔沿用该 child request id 自动新建顺序 attempt，默认总计最多 3 次 POST；成功兄弟不重提，串行链仅在该段成功后推进下游 |
| H3 阶段其他确定失败，或自动额度耗尽 | 用户确认“重试生成”后使用新父请求 id；服务端只复用状态成功且成片文件仍存在的段，并给出本次新增付费任务数 |
| 全部分段成功但本地拼接失败 | 即使会话级成片已半发布，仍展示成片与恢复区；用户确认“重试拼接”后复用原请求 id 和冻结输入，只在本地重拼；本次新增付费 H3 子任务为 0 |
| 某段提交结果未知 | 停止后续新提交并锁定整批，先去供应商核对，不允许自动或人工重提 |
| 历史 plan v1 含 11–15 秒段 | 只允许按已有 attempt 做 GET 恢复；缺少已有 attempt 时不创建新付费 POST |
| 校验 H3 分段原始输出 | receipt、输入与输出哈希必须匹配；成片不得比源片段目标短超过一帧，也不得比整秒请求长超过 1 秒 |
| 全部分段成功 | 归一化后按顺序拼接，校验总时长并原子写入会话级 `generated.mp4` |

## 边界

- 超过 300 秒、无法形成合法片段或台词跨越安全边界时，在任何付费请求前失败。
- 一期长视频不支持改写、翻译、编辑或自定义台词；这些模式返回明确错误，不静默降级。
- 拼接失败只重做本地拼接，不重新提交 H3。
- 启动恢复默认只 GET 已知 child；唯一自动新 POST 例外是 receipt、task id 和失败诊断完整的 `h3_provider_failed` 仍有额度，或其后已落盘但尚未 POST 的自动 attempt。
- 原始分段输出的容差只用于复用已付费产物；最终拼接仍按源片段帧预算精确裁剪或补齐，并以全片时长验收。
- 首尾帧和连续性提示词只能提高连贯性，不承诺无缝或人物绝对一致；该链路不是供应商原生 extend。
- 当前网页只提供快速模式，首次新建长视频固定提交 `fast_mode=true`，不提供模式开关。后端继续兼容显式 `false`；已经创建的 generation 始终复用服务端冻结值，历史任务缺字段仍按关闭处理。

## 例子

- 输入：15 秒同镜头视频 → 输出：1 个多图参考任务和约 15 秒成片。
- 输入：15.1 秒同镜头视频 → 输出：至少 2 个多图参考子任务，每段请求不超过 14 秒。
- 输入：从当前网页新建 30 秒视频 → 输出：网页固定提交快速模式，3 个子任务使用 plan 冻结共享边界、无需等待上一段成片即可快速提交；供应商可自行排队，最终仍按原顺序拼接。
- 输入：兼容调用显式提交 `fast_mode=false` → 输出：3 个按链顺序生成的多图参考子任务和约 30 秒成片。
