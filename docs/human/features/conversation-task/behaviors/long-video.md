# 长视频分段生成

## 规则

| 当 | 则 |
| --- | --- |
| 源视频不超过 10 秒 | 保持现有单个 H3 多图参考任务，不改变已有结果与付费语义 |
| 源视频超过 10 秒且不超过 300 秒 | 按场景规划连续片段，每段 1–15 秒，并在确认页显示子任务数量 |
| 两段属于同一镜头 | 下一段使用上一段生成尾帧作为首帧，并使用当前源片段末帧作为目标尾帧 |
| 边界是硬切 | 新片段从源视频首帧与末帧独立起链，不继承上一镜头尾帧 |
| 长视频选择自动台词 | H3 分段音轨不进入成片，最终复用完整源视频音轨 |
| 长视频选择无台词 | H3 分段音轨不进入成片，最终输出静音视频 |
| 某段确定失败 | 新请求只重做失败段；已成功段不再次付费生成 |
| 某段提交结果未知 | 停止后续新提交并锁定整批，先去供应商核对，不允许自动或人工重提 |
| 全部分段成功 | 归一化后按顺序拼接，校验总时长并原子写入会话级 `generated.mp4` |

## 边界

- 超过 300 秒、无法形成合法片段或台词跨越安全边界时，在任何付费请求前失败。
- 一期长视频不支持改写、翻译、编辑或自定义台词；这些模式返回明确错误，不静默降级。
- 拼接失败只重做本地拼接，不重新提交 H3。

## 例子

- 输入：15 秒同镜头视频 → 输出：1 个 FL2VA 子任务和约 15 秒成片。
- 输入：30 秒、两个连续 15 秒片段 → 输出：2 个按链顺序生成的 FL2VA 子任务和约 30 秒成片。
