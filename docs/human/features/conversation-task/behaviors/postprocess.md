# 后处理（Seedream 图像编辑）

## 规则

| 当 | 则 |
| --- | --- |
| 会话 `done` | 关键帧区标题旁显示「后处理」按钮；`postprocess_enabled` 为假（接口未开放）时按钮禁用并标注「待开放（接口预留）」 |
| `postprocess.status == "running"` | 按钮转「处理中…」禁用，标注「正在逐帧优化，请稍候…」，页面沿用 2s 轮询直到终态 |
| 点击「后处理」 | 弹窗（原生 dialog）列出四选项：换背景 / 含人脸遮挡 / 去字幕水印 / 去版权物品；至少勾选一项才可点「确认处理」；「取消」或 Esc 关闭 |
| 点「确认处理」 | 提交 `{"options": {...勾选...}, "confirm": true}`；成功后弹窗关闭、按钮转「处理中…」；失败（如 422/409/501）在弹窗内显示错误并恢复可编辑 |
| `postprocess.status == "done"` | 在原关键帧 grid 后追加「优化后」grid（同样的卡片样式与放大灯箱），取 `postprocess.frames` 列出的帧；多段模式优化图逐段附在该段关键帧 grid 之后 |
| `postprocess.status == "failed"` | 关键帧区显示错误文案（含失败帧名与原因）；已成功优化帧的对比图保留；按钮恢复可点（重跑跳过已有优化图） |
| 多段会话 `done` | 逐段渲染「第 N 段」卡片：段关键帧 grid + 段提示词卡片（含复制按钮）+ 段台词列表；顶层不再展示单段的关键帧/提示词区 |

## 边界

- 后处理可重复提交：`running` 中再提交 409；done/failed 后可**同选项**重跑，已有优化图的帧不重复处理
- 换选项重跑 → 409 `options changed since last run`（防止把上一次的优化图当成新选项的产物展示；想换选项需与编排者确认后续策略，当前一律拒绝）
- 人脸遮挡选项对每帧先做人脸检测：无人脸的帧不做该处理（有其他勾选项则只做其他项；无适用选项的帧整帧跳过）
- 人脸检测依赖 cv2 自带 haarcascade 数据（opencv-python-headless 4.x）：数据不可用时勾选「含人脸遮挡」提交直接被拒（503 `face detection data unavailable`），不会静默跳过
- 有人脸被处理时，该帧所属段（或单段）的提示词末尾追加动作线（放下手 + 正常节奏后续剧情），显示与复制内容同步更新
- 后处理不改变会话 `status`（始终 `done`），进度与结果只看 detail 的 `postprocess` 字段

## 例子

- 输入：打开一个 `done` 会话（接口已开放）→ 点「后处理」→ 勾「换背景」→ 确认 → 输出：按钮「处理中…」，完成后关键帧区出现「优化后」网格
- 输入：勾「含人脸遮挡」且某帧无人脸 → 输出：该帧只按其余勾选项处理，不生成遮挡图
