# 视觉语言与页面密度

## 用户看到什么

3213 使用类似现代大模型工作台的三层结构：浅灰会话侧栏、固定顶栏、居中的白色任务内容流。页面本身固定在浏览器视口内，长内容只在主内容区滚动；切换会话、生成和后处理时，侧栏与顶栏不随内容长度消失。

分析完成后的信息顺序固定为：

1. 紧凑的会话结论与源视频；
2. 分析指标、关键帧、识别台词和分段产物；
3. 提示词与生成设置；
4. 生成状态、后处理、最终成片和次要时间信息。

## 与确认预览版逐项对照

| 项目 | 禁止回到的现状 | 目标约束 |
| --- | --- | --- |
| 页面骨架 | 文档随卡片增长到多屏，浏览器整体滚动 | 工作台高等于视口；仅主内容区和会话列表滚动 |
| 内容宽度 | 约 72rem 的后台管理页面 | 桌面任务流不超过 56.25rem，居中呈现 |
| 信息表面 | 每个区块都是厚重白色大卡片 | 只在有明确边界、操作或状态时使用 AntD Card；连续阅读内容用 Typography、Descriptions、Collapse、Alert 分区 |
| 源视频 | 全宽 16:9 大卡片占据首屏 | 桌面为右侧紧凑媒体卡，移动端回到单列；保持真实播放器和认证加载 |
| 分析摘要 | 标题、消息和摘要重复 | 一次结论标题、一次状态标签；指标使用紧凑 Descriptions |
| 关键帧 | 大卡片包围图片网格 | 使用 AntD Image.PreviewGroup 的紧凑网格，标题为弱层级文本 |
| 台词 | 与指标混在大卡片内 | 独立的浅色内容区，时间和正文有清晰层级 |
| 提示词 | Card 内再套 Collapse | 以 AntD Collapse 为主表面，编辑、冲突和锁定能力不变 |
| 生成参数 | 独立厚重表单卡 | 轻量参数区；控件、推荐值、冻结摘要和付费门禁不变 |
| 时间信息 | 单独占一张大卡 | 作为内容流末尾的次要文本展示 |
| 移动端 | 桌面结构简单挤压 | 侧栏使用 Drawer；媒体、指标、表单变单列且无横向滚动 |

## 统一规则

- 可见控件、反馈和表面必须来自 `src/ui/antd.ts` 暴露的 AntD/AntD X 组件；不新增手搓按钮、卡片、输入、标签、进度、弹窗或图标。
- 页面组合只使用项目 class；不得覆盖 `.ant-*` 内部结构，不得使用 inline style、裸色值或自定义视觉变量。`src/app/**` 与 `src/features/**` 的 CSS 只允许几何、滚动、响应式和媒体宽高比，背景、边框、圆角、阴影、字体及颜色必须由组件和主题提供。
- 颜色、字体、圆角、阴影和控件尺寸只在 `src/ui/theme.tsx` 定义；页面 CSS 只承担布局、滚动、宽高比和响应式排列。
- 新页面优先复用现有骨架、内容宽度和分区组件。若必须新增视觉模式，先更新本文件和 Agent reference，再新增截图基线。
- 272px 侧栏、900px 内容上限、`100dvh` 工作台、四个固定视口截图和“仅正文滚动”几何断言属于发布门禁；不得通过放宽断言或只更新截图绕过。
- 不为贴近预览版引入后端不存在的聊天输入、假状态、假指标或假媒体。
