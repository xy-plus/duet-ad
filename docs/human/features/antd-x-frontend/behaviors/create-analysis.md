# 创建会话与分析进度

## 规则

| 当 | 则 |
| --- | --- |
| 用户选择“链接输入”或“上传文件” | 切换来源时清空另一种来源，文件名不会被当成 URL，旧 URL 也不会随文件提交 |
| 用户选择台词处理 | 可选保持原文、改写或翻译；翻译目标语言允许自由输入且不能为空 |
| 用户点击创建 | 冻结来源、说明、台词选项和 `client_request_id`，锁住全部创建控件并显示真实 XHR 上传进度 |
| 网络或上传失败后直接重试 | 复用同一份冻结 intent 和请求 id；用户修改/关闭错误后才生成新的 intent |
| 服务端返回会话 id | 打开该会话；分析 bubble、列表 badge 与摘要都只显示服务端状态和产物 |
| 分析仍在 queued/processing | 每 2 秒轮询详情；失败显示服务端错误，完成后显示真实时长、关键帧数和台词数 |

## 边界

- 文件或 URL 至少提供一种；翻译模式必须提供目标语言，说明文字可为空。
- 上传进度来自浏览器 XHR；前端不制造完成百分比、分析计时器或成功消息。
- 媒体信息只展示 API 已提供的时长、关键帧和台词，不猜测 codec、节奏、镜头数或分辨率。
- 创建自动重试由用户触发；TanStack mutation 自身 `retry=false`。

## 例子

- 输入：先填写 URL，随后切到文件并选择 `source.mp4` → 输出：请求只含文件，不含原 URL。
- 输入：文件上传到 63% 后网络断开，用户未修改表单直接重试 → 输出：沿用首次冻结的文件、选项和请求 id。
