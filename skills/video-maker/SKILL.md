# video-maker：用提示词让图片动起来

## 0. 核心逻辑与目录

所有路径相对当前工作目录。

- 核心逻辑：**用提示词让图片动起来**。看图理解叙事，选出若干定格状态（关键帧），写一段提示词描述这些状态如何依次运动、变化。
- 输入目录 `work/`（外部程序已备好，抽帧不由你执行）：
  - `NN_frame_*.png`：按每秒 4 帧抽取的全部帧
  - `contact_sheet_01.jpg、02.jpg …`：分页联系表
  - `manifest.json`：源视频时长、尺寸、帧率、总帧数
  - `scenes.json`：场景划分清单（每场景起止时间与帧分组，选帧参考、不必严格遵守）
  - `voice_lines.json`：台词（可选：JSON 数组 `[{"text", "start_s", "end_s"}]`）
- 输出（固定路径）：
  - `work/keyframes/01.png、02.png … N.png`：选定的关键帧，按时间序命名
  - `work/prompt.txt`：提示词全文
- 你只处理图片与文字文件，没有也不需要访问视频 `[C01]`。
- 用到的工具只有一个：`scripts/crop_image.py`（裁掉帧上的字幕/水印）。

## 1. 约束

- `C01` 只处理图片与文字文件；不尝试访问视频。
- `C02` 眼见为实：写下的每个画面细节都能指到具体帧。
- `C03` 关键帧数量上限 9 张（当前生成链参考图上限）；张数由内容决定，不凑数；用户指定数量时按用户。
- `C04` 一帧一个主导状态；帧序即时间序。
- `C05` 每个结果帧有前置的原因帧。
- `C06` 提示词用用户的语言；口播翻译模式下用后端 prompt 指明的目标语言。
- `C07` 提示词只写叙事逻辑：发生什么、什么顺序、什么因果；不写具体秒数。
- `C08` 因果可见：先有动作，后有变化；动作到哪里，变化到哪里；没被碰到的地方保持原样。
- `C09` 目标时长 = 源时长与 15 秒取较小值；源视频超过 15 秒时做取舍，只保留最有意义的部分。
- `C10` 关键帧尽量不含字幕和水印；无法避免时用裁剪工具裁掉。

## 2. 步骤

### 第 1 步　看懂叙事
逐页看 `work/` 下的联系表，必要时打开单帧确认细节；理清因果链：初始状态 → 动作 → 结果 `[C02]`。目标时长与取舍按 `[C09]`（源时长见 `work/manifest.json`）。

参考 `work/scenes.json` 的场景分组：不需要逐页看完全部联系表，按场景分组按需查看即可；场景划分只是参考，不必严格遵守——叙事因果链以你实际看到的帧为准。

### 第 2 步　选关键帧 `[C03 C04 C05 C10]`
从已有帧里按叙事顺序挑选，参考序：建立环境 → 初始状态 → 引入工具/产品 → 施加动作 → 反应 → 主要动作 → 收尾 → 最终结果。帧要清晰稳定、主体可见、遮挡少、无字幕水印；避不开就裁：
```
python scripts/crop_image.py <帧图片> --box <左,上,右,下>
```
选定的帧复制进 `work/keyframes/`，按时间序重命名为 `01.png、02.png … N.png`。

### 第 3 步　写提示词 `[C06 C07 C08]`
按第 3 节骨架逐字段填写，每个画面细节都来自检查过的帧 `[C02]`；写入 `work/prompt.txt`。

### 第 4 步　收产物
确认 `work/keyframes/` 与 `work/prompt.txt` 就位，返回交付物清单和提示词全文。

## 3. 提示词骨架

段序固定；括号字段只能用检查所得填写 `[C02]`。

```text
生成一支 [目标时长] 秒、与源视频一致的[比例]、[分辨率，默认 720p] 的[主题]短视频。

拍摄风格：[从帧里观察到的源视频风格：机位、手持感、光线、质感，与源视频保持一致]。无字幕、贴纸或水印等叠加元素。

叙事（让图片动起来）：
从图片1 的状态开始，[先发生什么]；接着[动作如何推进]；（多个场景时写明何时直接切镜）……最后到达图片N 的[最终状态]。

因果：[先看到动作，再看到变化；动作到哪里，变化到哪里；没被碰到的地方不变]
```

### 口播台词（`voice_lines.json` 存在时）

台词逐句编排进叙事，每句 1.5~2.5 秒节奏，逐句出现在对应的画面阶段（句序与帧序对应）：

- 台词放双引号：`@图片N中的角色，说出台词："…"，嘴型与画面同步`
- 「不要生成背景音乐」由后端机械添加进 prompt，你不写这一行。
