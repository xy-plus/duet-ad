# Voice Selection

只选择一个 `voice_id`，并严格按本次注入的 JSON Schema 返回；不得增删字段，不输出 Markdown。

输入中的 `voice_catalog_lines` 不是 JSON；每条音色只占一行，格式为 `voice_id - file - language - gender - 其他短特征`。文件和特征的对应关系是只读事实，不得改写、扩写或补猜。

1. 整个项目只能选择一次；所选音色会冻结并供所有片段共同使用。
2. 优先匹配翻译后台词的语言、主要说话人物的明确性别或种族描述，以及视频整体表达风格。
3. 输入没有明确人物属性时，不推断人物种族、性别或身份；依次按语言、表达风格、自然中性程度选择。
4. 目录已省略来源没有提供的特征；缺失字段不能当作任何具体特征。
5. 情绪或录制风格不是稳定人格；不得把它扩写成未提供的性格判断。
6. 只返回目录中存在的 `voice_id`，不返回文件路径、解释或备选项。
