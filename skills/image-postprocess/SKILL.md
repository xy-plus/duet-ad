# image-postprocess

## 目标

为了降低素材重复度，在关键帧进入视频生成前，为可能执行的 Seedream 二次编辑生成提示词。第一优先级是最终视频连续性和现实合理性；任何扭曲、元素突变、物理或接触关系异常都一票否决。人脸或原位表面材质替换仅是用于去重的第二优先级，只有通过第一层才评价。

本 Skill 只生成提示词，不编辑图片、不调用 Seedream。生成提示词不代表图片二次编辑一定执行、成功或被视频生成采用。

## 输入

只允许读取：

- `work/request.json`：
  - `edit_mode` 只能是 `anchor_consistency` 或 `independent_parallel`。
  - `segments` 按段号升序提供 `index`、`chain_id`、`join_mode`。
  - 短视频只有第 0 段；多段视频的段号从 1 连续递增。
- `work/segments/<段号>/keyframes/01.png、02.png …`：对应片段的全部冻结关键帧。

不得读取视频、视频生成提示词、台词、音频、项目目录、其他路径或未列出的文件。

## 唯一输出

只写 `work/image_optimization.json`，不得写其他文件。输出必须是 UTF-8 JSON，结构严格如下：

```json
{
  "version": 1,
  "segment_indices": [1, 2],
  "global_elements": [
    {
      "id": "PERSON_01",
      "kind": "person",
      "source": "跨段重复出现的原人物可见特征",
      "replacement": "统一的新人物身份和可复用外观特征",
      "segments": [1, 2]
    }
  ],
  "segment_prompts": [
    {
      "segment_index": 1,
      "prompt": "本段真实提交给 Seedream 的完整提示词"
    },
    {
      "segment_index": 2,
      "prompt": "本段真实提交给 Seedream 的完整提示词"
    }
  ]
}
```

- `segment_indices` 必须与请求段号完全一致。
- `segment_prompts` 必须覆盖全部段并按段号升序排列；每段提示词非空，以 Unicode 字符数计不超过 140 个字符。
- 短视频的 `segment_indices` 是 `[0]`，`global_elements` 必须是空数组。
- 除规定字段外不得增加字段；不得用 Markdown 代码围栏包裹 JSON。

## 项目级安全决策

1. 先检查全项目全部关键帧，再决定替换策略；去重目标只能是 `人物外观` 或 `背景表面材质`。把同一 `chain_id`，或可见为同一人物、同一核心前景对象或同一互动关系的段连成相关组件；不可见的信息不得推断或虚构。每个相关组件只能在项目级一次冻结一种策略，不得逐帧或逐段改策略。
2. 只要相关段出现任何手与玩具、商品或功能道具互动，相关段只允许背景表面原位材质映射，不得生成新场景或新房间；整个相关组件统一沿用该安全策略。人物和服装不得变化，所有前景对象、像素语义和关系都保持不变。
3. 先在全项目识别稳定的原表面类别，包括墙面、砖面、木格栅、地板等；为每类冻结同一替换材质与颜色，并在跨帧、跨段逐字复用。每个映射只改变原表面原位置的材质和颜色，不得把一种表面扩张到另一种表面；跨段重复且实际替换的类别逐字复用同一个 `SCENE replacement`。
4. 无高风险时保留既有人物路线，但人物策略只换脸：仅当人物稳定清晰、同一人物在所有拟替换段都可确认，且全部相关组件统一使用同一个新面部身份不会降低连续性和现实合理性时才允许。新面部保持可见的性别呈现、相近年龄和整体气质，长相略有不同；不得推断身份或具体族裔，发型、身体、服装与背景不得变化。
5. 未同时满足人物策略全部条件时选择原位表面材质映射。画质、功能道具、玩具、商品、宠物不得作为差异化目标；没有人物时不得新增人物。

## 不可编辑内容

- 核心商品、功能道具、玩具、手部，以及人与物/物与物的握持、接触、插入、插接、对齐、连接、遮挡、前后顺序、数量、结构、方向，全部不可编辑；不得同类改款。
- 保持目标帧自身的画幅、裁切、机位、镜头、透视、景别、构图、光线、焦点、景深、人物与动物数量、姿态、动作、视线，以及非目标元素的位置、比例和可见部分。
- 墙体、门窗、插座、踢脚线、墙地交界的几何与位置全部冻结；不得新增、删除或移动固定构件、家具、陈设，不得改变人物与物体的地面接触。
- 提示词只点名目标帧中最容易误改的剧情核心物体和关系，不复述全部构图或叙事，不描述视频过程、运镜、转场、台词或音频。
- 禁止增删任何物体；禁止恢复、新增或删除字幕、文字、Logo、水印、贴纸、界面元素、品牌标识或乱码。

## 跨段一致性

1. `global_elements` 只允许实际跨段替换的 `PERSON`、`SCENE`；`OUTFIT` 仅在服装真实替换时允许，但本策略默认不得替换服装。PROP、PRODUCT、SUBJECT 不得建立新映射。单段元素和仅被保持的元素不进入。
2. 人脸使用 `PERSON/person`，原表面类别的材质与颜色映射使用 `SCENE/scene`；真实服装替换才使用 `OUTFIT/outfit`。同类 ID 从 `01` 连续编号；整个数组按完整 `id` 的字典序输出。
3. `source` 只写识别原人脸或原表面类别所需的稳定可见特征；`replacement` 只写可直接复用的新面部身份，或冻结的替换材质与颜色，不写构图、动作、光线、位置或关系。
4. `segments` 只列实际执行该替换的段号，升序、去重且至少包含两段。相同原表面类别必须在跨帧、跨段逐字复用同一个 `SCENE replacement`。
5. 同一 `chain_id` 的 `continue` 段优先视为连续画面；`hard_cut` 不自动代表人物或场景变化，仍以可见证据判断。

## 每段 Seedream 提示词

每段所有关键帧共享一份可直接提交给 Seedream 的提示词，不得包含 Markdown、解释或分析。每段提示词恰好两句，整段不超过 140 个字符，并遵守以下硬约束：

1. 原位表面策略的第一句必须逐一写明本段实际替换的原表面类别及其冻结材质与颜色，并明确每种原表面只在原位置变材质；保持墙体、门窗、插座、踢脚线、墙地交界的几何与位置、透视、光线方向及人物与物体的地面接触，不得新增、删除或移动固定构件、家具、陈设。不得要求人物重绘或服装变化。极少数安全人物策略的第一句只写全项目统一的 `PERSON replacement`，明确人物策略只换脸且发型、身体、服装与背景不变。
2. 第二句必须保护人物、服装、手、玩具、商品及握持、插接、对齐、遮挡关系，并明确不得增删物体、文字或 Logo；仍只点名一个最危险的实际关系，不得写第二个关系、全景复述、物体清单、画质美化、真实摄影增强或其他编辑目标。

把模式约束压入第二句且不得因此增加句子：`anchor_consistency` 说明当前图是目标，其他图只提供目标材质或身份参考，不得传递构图、动作、物体或关系；`independent_parallel` 不写任何参考图语句，只说明当前图是唯一目标。

不得使用固定长开头或额外句子。生成前自行计数整段提示词的 Unicode 字符数；超长必须重写，不能截断。确认第一层安全门槛、两句结构、单一目标和所有不可编辑关系均满足后，才写入 JSON。
