# image-postprocess

## 目标

为了降低素材重复度，为冻结关键帧生成 Seedream 二次编辑提示词。每段只替换一个人物外观或背景，其余画面不变；同一目标跨段使用同一个新设计。

本 Skill 只生成提示词，不编辑图片、不调用 Seedream。

## 决策优先级

1. 第一优先级是最终视频连续性和现实合理性；任何扭曲、元素突变、物理或接触关系异常均一票否决。
2. 人物或背景替换仅是第二优先级的去重手段，只有通过第一层才评价；不得为完成换人牺牲连续性。
3. 人物替换风险高时，整个相关组件必须项目级统一回退背景。

## 输入

只允许读取：

- `work/request.json`：`edit_mode` 只能是 `anchor_consistency` 或 `independent_parallel`；`segments` 按段号升序提供 `index`、`chain_id`、`join_mode`。
- `work/segments/<段号>/keyframes/01.png、02.png …`：对应片段的全部冻结关键帧。

不得读取视频、视频提示词、台词、音频、项目目录、其他路径或未列出的文件。

## 唯一输出

只写 UTF-8 `work/image_optimization.json`，不得写其他文件，结构严格如下：

```json
{
  "version": 1,
  "segment_indices": [1, 2],
  "global_elements": [
    {
      "id": "PERSON_01",
      "kind": "person",
      "source": "跨段重复出现的原人物可见特征",
      "replacement": "统一的新人物身份和可复用外观特征",
      "segments": [1, 2]
    }
  ],
  "segment_prompts": [
    {"segment_index": 1, "prompt": "本段真实提交给 Seedream 的完整提示词"},
    {"segment_index": 2, "prompt": "本段真实提交给 Seedream 的完整提示词"}
  ]
}
```

- `segment_indices` 必须与请求段号完全一致。
- `segment_prompts` 必须覆盖全部段并按段号升序；每段提示词非空，以 Unicode 字符数计不超过 120 个字符且恰好两句话。
- 短视频段号是 `[0]`，`global_elements` 必须为空数组。
- 不得增加字段或用 Markdown 包裹 JSON。

## 选择唯一目标

1. 先检查项目全部片段的全部冻结关键帧，在项目级识别每个人物及其相关段，再对整个相关组件统一选择`人物外观`或`背景`，严格二选一，不得逐段独立决策。
2. 人物外观是一个人的新面孔，可连同同色、同用途、同风格但不同款的服装设计；保持可见的性别呈现、相近年龄和整体气质，长相略有不同，不推断身份或族裔。
3. 人物脸部和服装足够可见、能建立稳定同一性时，优先选择人物外观；选择人物外观时不得修改背景，选择背景时不得修改人物或服装。
4. 背景保持场景类别与功能，设计同类型但不重复的真实背景。
5. 玩具、商品、道具、宠物永不作为替换目标，也不进入 `global_elements`。没有人物时不得新增人物，不虚构不可见信息。

## 项目级一致性

1. 同一人物跨段重复且选择人物时，只有全部相关段安全可见才执行；所有安全可见的相关段都选择人物，PERSON、OUTFIT 的 replacement 逐字复用，相关段不得改背景。任何相关段人物不安全或不可见时，整个相关组件统一选择背景。
2. 只有真正被替换且跨段重复的 PERSON、OUTFIT、SCENE 才进入 `global_elements`；global_elements 只允许 PERSON、OUTFIT、SCENE。
3. 人物用 `PERSON/person`，随人物替换的服装用 `OUTFIT/outfit`，背景用 `SCENE/scene`；同类 ID 从 `01` 连续编号，所有 ID 按完整字符串字典序输出。
4. `source` 只写原目标的稳定可见特征；`replacement` 只写可复用的新身份或设计；`segments` 升序、去重且至少两段。相同替换描述必须跨段逐字复用。
5. `continue` 和 `hard_cut` 只辅助判断，以所有关键帧的可见证据为准。

## 每段提示词

每段全部关键帧共享一份提示词。提示词恰好两句话，只用两个句号分句和收尾，不写 Markdown、解释或分析。

1. 人物目标的第一句只写新面孔与同色同风格不同款服装，避免堆砌长相细节，不得写任何保持项；背景目标的第一句只写同类新背景。
2. 人物目标的第二句明确只有人物外观和服装表面可变，锁定构图、机位、光线、人物动作及目标人物的头部位置、大小、朝向和画面裁切；只点名一个最危险的手与功能道具关系，按可见证据从接触、插入或对齐关系中选一项；以“其余一切不变、真实摄影、无文字或 Logo”收束。背景目标的第二句明确只有背景可变并使用相同收束。

禁止画质优化、风格化、全场景复述或道具改款。

- `independent_parallel`：不写参考图角色说明。
- `anchor_consistency`：仅在第二句加入“参考图只认目标身份或设计，不参考构图”。

生成前自行计数 Unicode 字符数并核对两句结构；接近上限先删冗余词，不得省略上述锁定项，超长必须重写，不能截断。确认第一句只有一个替换目标，第二句没有引入新设计后再写 JSON。
