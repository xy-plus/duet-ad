# image-postprocess

## 目标

这些关键帧是视频生成前的中间素材。用户可能选择移除字幕、移除 Logo，并使用 Seedream 进行图片二次编辑。

本 Skill 只生成图片二次编辑提示词，不修改图片、不调用 Seedream、不生成视频提示词。生成提示词不代表二次编辑一定执行、成功或被视频生成采用。

## 输入与输出

只允许读取：

- `work/keyframes/01.png、02.png …`：同一片段的冻结关键帧。
- `work/request.json`：`edit_mode` 只能是 `independent_parallel` 或 `anchor_consistency`。

固定输出 `work/image_optimization_prompt.txt`：

- 本段所有关键帧共享一份提示词。
- 文本会原样展示给用户，确认后原样提交 Seedream。
- 使用简体中文 UTF-8 纯文本，非空且不超过 32KB；不包含 Markdown、解释或分析。
- 不得读取视频、视频生成提示词、台词、音频、其他片段或工作目录外的文件。

## 规则

1. 检查全部关键帧，只描述实际可见内容，不猜测。
2. 不写视频时长、运镜、转场、动作过程、台词、口型或音频。
3. 保持画幅、裁切、机位、透视、构图、人物数量与动作状态。
4. 保持核心主体或商品的类别、数量、结构、主要颜色、功能部件、位置及人与物的接触关系。
5. 可以替换人物面孔、调整服装款式、有限修改非核心环境细节并改善画面质量。
6. 同一人物、服装、商品、道具和场景在整个片段中保持一致。
7. 不得新增或删除重要人物、商品、道具及真实商品部件。
8. 不得恢复或新增字幕、文字、Logo、水印、贴纸、界面元素或乱码。
9. 保持真实摄影质感，不擅自改成插画、卡通或 3D 风格。

## 图片角色

`independent_parallel` 必须说明：

> 输入图片是本次唯一的编辑目标，只编辑当前图片。

`anchor_consistency` 必须说明：

> 输入图片列表中的第一张是本次唯一的编辑目标。其余图片只用于识别同一片段中重复出现的人物、核心主体、服装、道具和场景，并保持跨帧一致性。不得复制参考图片的构图、动作或物体位置，也不得把只存在于参考图片中的元素添加到目标图片。

## 步骤

1. 读取 `request.json` 并检查全部关键帧。
2. 识别核心人物、商品、道具、场景及必须跨帧一致的元素。
3. 根据编辑模式写明目标图片和参考图片的角色。
4. 用当前片段的具体画面信息写出保持项、允许修改项和禁止项，不得只写“保持主体不变”等空泛要求。
5. 将可直接提交给 Seedream 的最终文本写入 `work/image_optimization_prompt.txt`。

提示词开头应表达：

> 对本次目标图片进行内容级二次编辑，并保持其作为同一视频片段关键帧所需的镜头结构、人物动作、核心主体和跨帧连续性。
