# image-postprocess

## 目标

第一优先级是最终视频连续性和现实合理性；任何扭曲、元素突变、物理或接触关系异常都一票否决。保持叙事内核和关系不变，只改变表象。人物或背景替换仅是用于去重的第二优先级，只有通过第一层才评价。

本 Skill 只生成提示词，不编辑图片、不调用 Seedream。生成提示词不代表图片二次编辑一定执行、成功或被视频生成采用。

## 输入

只允许读取：

- `work/request.json`：`edit_mode` 只能是 `anchor_consistency` 或 `independent_parallel`；`segments` 按段号升序提供 `index`、`chain_id`、`join_mode`。
- `work/segments/<段号>/keyframes/01.png、02.png …`：对应片段的全部冻结关键帧。

不得读取视频、视频生成提示词、台词、音频、项目目录、其他路径或未列出的文件。

## 唯一输出

只写 UTF-8 `work/image_optimization.json`，不得写其他文件，结构严格如下：

```json
{
  "version": 1,
  "segment_indices": [1, 2],
  "global_elements": [
    {
      "id": "PERSON_01",
      "kind": "person",
      "source": "跨段重复出现的原人物可见特征",
      "replacement": "统一的新人物身份和可复用外观特征",
      "segments": [1, 2]
    }
  ],
  "segment_prompts": [
    {"segment_index": 1, "prompt": "本段真实提交给 Seedream 的完整提示词"},
    {"segment_index": 2, "prompt": "本段真实提交给 Seedream 的完整提示词"}
  ]
}
```

- `segment_indices` 必须与请求段号完全一致。
- `segment_prompts` 必须覆盖全部段并按段号升序排列；每段提示词非空、恰好两句。
- 短视频的 `segment_indices` 是 `[0]`，`global_elements` 必须是空数组。
- 除规定字段外不得增加字段；不得用 Markdown 代码围栏包裹 JSON。

## 项目级安全决策

1. 先检查全项目全部关键帧；去重目标只能是 `人物外观` 或 `背景`。全项目构建跨段相关组件：把同一 `chain_id`，或可见为同一人物、同一场景或同一稳定背景/固定建筑表面、核心前景对象或互动关系的段连在一起；识别功能道具、商品、玩具或人与物互动，不得用不可见信息推断或虚构关联。
2. 每个组件只做一次策略选择并冻结，不得逐段摇摆。逐帧检查手与功能道具或玩具的握持、插接、对齐、接触和遮挡；任一相关段存在手—功能道具/玩具的高风险关系，整个组件统一选择背景路线，只替换背景；人物、服装、前景对象、像素语义和关系全不变。
3. 背景路线只选一个能在所有相关段稳定对应、面积尽量大的安全背景表面类别，优先地面，其次墙面；允许个别关键帧因裁切不可见，该帧不做其他编辑；不得映射全部背景或组合多个表面类别。
4. 对所选表面做原位材质映射：改为同功能、同表面类别但明显不同的材质或色调，并在所有相关段逐字复用同一个新设计和 `SCENE replacement`。保持原表面的边界、分块/拼缝、方向、透视和接触几何，并保持光线方向；保持墙体、门窗、插座、踢脚线、墙地交界等建筑几何与位置；固定构件、家具、陈设不得新增、删除或移动。不得描述或生成新房间。
5. 只有组件无上述高风险关系、找不到稳定安全背景表面，且同一人物可确认、人物在所有相关段都稳定清晰，换脸不会降低连续性和现实合理性时，才统一选择人物路线。只替换同一人物的新脸，新脸长相略有不同；保持可见的性别呈现、肤色和整体风格、年龄和气质，不推断身份或具体族裔；只换脸，不换服装，锁定头部位置、大小、朝向、裁切和遮挡；跨段 `PERSON replacement` 必须逐字复用。
6. 任何组件只要背景路线和人物路线都不能证明安全，就输出两句不改动提示词，不建立 `global_elements`；这包括无人、人物不清晰且无稳定安全背景表面的普通组件。高风险组件找不到合格表面时放弃去重，不得退到人物路线。画质、功能道具、玩具、商品、宠物不得作为差异化目标；没有人物时不得新增人物。

## 不可编辑内容

- 核心商品、功能道具、玩具、手部，以及人与物/物与物的握持、接触、插入、对齐、连接、遮挡、前后顺序、数量、结构、方向，全部不可编辑；不得同类改款。
- 保持目标帧自身的画幅、裁切、机位、镜头、透视、景别、构图、光线、焦点、景深、人物与动物数量、姿态、动作、视线，以及非目标元素的位置、比例和可见部分。
- 禁止恢复或新增字幕、文字、Logo、水印、贴纸、界面元素、品牌标识或乱码。

## 跨段一致性

1. 本 Skill 的 `global_elements` 只允许 `PERSON`、`SCENE`；不得输出 `OUTFIT`、`PROP`、`PRODUCT`、`SUBJECT`。只收录实际跨段替换且跨至少两段重复的 PERSON 或 SCENE；单段或仅保持的元素不进入。
2. 人物使用 `PERSON/person`，背景使用 `SCENE/scene`；同类 ID 从 `01` 连续编号，数组按完整 `id` 的字典序输出。
3. `source` 只写原目标的稳定可见特征；`replacement` 只写可复用的新脸或新设计，不写构图、动作、光线、位置或关系。
4. `segments` 只列实际替换的段号，升序、去重且至少两段。每个背景组件只为选中的一个表面类别建立 `SCENE`；逐字复用同一 `SCENE replacement` 或 `PERSON replacement`。
5. 同一 `chain_id` 的 `continue` 段优先视为连续画面；`hard_cut` 不自动代表人物或场景变化，仍按可见证据判断。

## 每段 Seedream 提示词

每段所有关键帧共享一份可直接提交给 Seedream 的提示词。第一句只聚焦唯一替换目标及其原位条件；第二句写完整保护。保持简洁，但不得为缩短删除安全关系；禁止全景复述、画质美化或物体清单。不得包含 Markdown、解释或分析。

### 背景路线

1. 第一句明确只编辑每张图中可见的目标表面；目标表面不可见的图片不做任何改变。只写所选表面的原位材质或色调替换，并保持其边界、分块/拼缝、方向、透视、接触几何和光线方向；不得描述新房间、诱导新增陈设、重绘人物或改变服装。
2. 第二句明确固定构件、家具、陈设不得新增、删除或移动；人物、服装、手、玩具、商品及其握持、插接、对齐、遮挡关系全不变；禁止增删文字或 Logo，禁止真实摄影增强或其他编辑目标。

### 人物路线

1. 第一句只替换同一人物的新脸；保持可见的性别呈现、肤色和整体风格、年龄和气质，锁定头部位置、大小、朝向、裁切和遮挡。只换脸，不换服装、背景或身体其他部分。
2. 第二句明确固定构件、家具、陈设不得新增、删除或移动；人物除脸外、服装、手、玩具、商品及其握持、插接、对齐、遮挡关系全不变，并禁止增删文字或 Logo。

把模式约束压入第二句，不得增加第三句：`independent_parallel` 无需写“当前图是唯一目标”，不得写参考人物、参考角色或其他图；`anchor_consistency` 必须限制其他图的角色，说明其他图只提供目标设计，不传递人物、构图、动作、物体或关系。
