# image-postprocess

## 目标

为了降低素材重复度，在关键帧进入视频生成前，为可能执行的 Seedream 二次编辑生成提示词。

保持每张目标图自身的内容、机位、镜头、光线、构图和动作，只对人物、非人主体、服装、场景、道具等做受控差异化。同一原元素无论出现在同段还是跨段，都必须转换为同一个新元素或同一套新设计。

本 Skill 只生成提示词，不编辑图片、不调用 Seedream。生成提示词不代表图片二次编辑一定执行、成功或被视频生成采用。

## 输入

只允许读取：

- `work/request.json`：
  - `edit_mode` 只能是 `anchor_consistency` 或 `independent_parallel`。
  - `segments` 按段号升序提供 `index`、`chain_id`、`join_mode`。
  - 短视频只有第 0 段；多段视频的段号从 1 连续递增。
- `work/segments/<段号>/keyframes/01.png、02.png …`：对应片段的全部冻结关键帧。

不得读取视频、视频生成提示词、台词、音频、项目目录、其他路径或未列出的文件。

## 唯一输出

只写 `work/image_optimization.json`，不得写其他文件。输出必须是 UTF-8 JSON，结构严格如下：

```json
{
  "version": 1,
  "segment_indices": [1, 2],
  "global_elements": [
    {
      "id": "PERSON_01",
      "kind": "person",
      "source": "跨段重复出现的原人物可见特征",
      "replacement": "统一的新人物身份和可复用外观特征",
      "segments": [1, 2]
    }
  ],
  "segment_prompts": [
    {
      "segment_index": 1,
      "prompt": "本段真实提交给 Seedream 的完整提示词"
    },
    {
      "segment_index": 2,
      "prompt": "本段真实提交给 Seedream 的完整提示词"
    }
  ]
}
```

- `segment_indices` 必须与请求段号完全一致。
- `segment_prompts` 必须覆盖全部段，按段号升序排列；每段提示词非空且不超过 32KB。
- 短视频的 `segment_indices` 是 `[0]`，`global_elements` 必须是空数组。
- 除规定字段外不得增加字段；不得用 Markdown 代码围栏包裹 JSON。

## 处理规则

1. 检查全部关键帧，只依据可见信息识别同段或跨段重复出现的人物、非人主体、服装、场景、道具和核心商品。
2. 先为跨段重复元素确定一次全局“原元素 → 新元素”映射，再为各段只在段内重复的元素确定具体、可复用的一一对应转换。
3. 同一原元素在所有相关提示词中必须逐字复用同一个 `replacement`，不得按帧或按段重新设计。
4. 人类使用 `PERSON/person`，宠物、动物等非人主体使用 `SUBJECT/subject`，其余使用 `OUTFIT/outfit`、`SCENE/scene`、`PROP/prop`、`PRODUCT/product`；不得把动物归为人物。
5. 同类 ID 从 `01` 连续编号；全部全局元素按 ID 升序输出。`segments` 只列元素实际出现的段号，必须升序、去重且至少包含两段。
6. `source` 只写足以识别原元素的稳定可见特征；`replacement` 只写统一的新身份或新设计。不得写任何单帧的构图、机位、景别、动作、光线、前后景或元素位置。
7. 同一 `chain_id` 的 `continue` 段优先视为连续画面；`hard_cut` 不自动代表人物、商品或场景发生变化，仍以可见证据判断。
8. 某元素只出现在一段时不进入 `global_elements`，但可以在该段提示词中建立段内统一方案。不可见的信息不得推断或虚构。

## 差异化要求

- 人物：面部信息足够可见时，换成同性别呈现、相近年龄、肤色、族裔外观风格和整体气质，但长相略有不同的自然新面孔；只描述可见外观，不命名或推断具体族裔、身份和个人。
- 非人主体：保持物种、体型、毛色和主要外观风格，换成外观略有不同但自然可信的另一个个体。
- 服装：保持主要颜色、用途和整体风格，改变具体款式，例如版型、领口、袖型、剪裁或面料纹理。
- 场景：保持类别和功能，例如仍然是同类厨房、车库或草地，但替换为同类型但不重复的真实场景；可以改变墙地材质、家具设施造型、植被或非核心背景细节。
- 非核心道具：保持用途、主要颜色和尺寸，换成同类型的不同款式。
- 核心商品：保持类别、数量、结构、主要颜色、功能部件和真实商品信息，不得增删或改造商品部件。
- 质量：完成内容差异化后，只可适度改善曝光、白平衡、噪点、压缩痕迹和自然清晰度，保持真实摄影质感。

没有人物时不得新增人物。禁止恢复或新增字幕、文字、Logo、水印、贴纸、界面元素、品牌标识或乱码。

## 每段 Seedream 提示词规则

每段所有关键帧共享一份提示词。提示词必须直接可提交给 Seedream，不得包含 Markdown、解释、分析、视频叙事、动作过程、运镜、转场、台词或音频。

Seedream 每次编辑时，第一张输入图片是唯一目标帧：

- 必须保持目标帧自身的画幅、裁切、机位、镜头、透视、景别、构图、光线、焦点、景深、人物与动物数量、姿态、动作、视线，以及元素的位置、比例、遮挡和接触关系。
- `anchor_consistency` 模式下，其他输入图片只用于识别重复元素并复用已经确定的新身份或新设计，不提供画面内容、构图、动作、机位、景别、光线或位置参考。
- 只转换目标帧自身可见的既有元素，不得从参考图片向目标帧新增人物、动物、商品、道具、门窗、家具或背景物体。
- 不得把某帧特有的空间描述升级为全段要求，例如“保持第一张图片的近距离俯拍机位”“手持玩具位于前景”“猫位于后方”。

每段提示词必须逐字以下段开头：

> 为降低素材重复度，对本次第一张输入图片进行受控内容级二次编辑。第一张输入是唯一目标帧；其他输入仅作为重复元素的新身份与新设计锚点，绝不作为构图或画面内容参考。每次均保持目标帧自身的机位、镜头、光线、构图、动作和元素位置。

随后依次写：

1. 本段差异化目标。
2. 本段可见元素的一一对应转换方案；跨段元素必须逐字采用相应全局 `replacement`。
3. 目标帧保持项。
4. 禁止事项。

输出前删除空泛画质描述、单帧叙事、空间布局复述，以及任何可能让参考图片覆盖目标帧内容的要求。
