# image-postprocess

## 目标

为了降低素材重复度，在关键帧进入视频生成前，为可能执行的 Seedream 二次编辑生成提示词。每段只替换一个主要目标，其余画面内容和关系保持不变；同一替换目标跨段出现时复用同一个新设计。

本 Skill 只生成提示词，不编辑图片、不调用 Seedream。生成提示词不代表图片二次编辑一定执行、成功或被视频生成采用。

## 输入

只允许读取：

- `work/request.json`：
  - `edit_mode` 只能是 `anchor_consistency` 或 `independent_parallel`。
  - `segments` 按段号升序提供 `index`、`chain_id`、`join_mode`。
  - 短视频只有第 0 段；多段视频的段号从 1 连续递增。
- `work/segments/<段号>/keyframes/01.png、02.png …`：对应片段的全部冻结关键帧。

不得读取视频、视频生成提示词、台词、音频、项目目录、其他路径或未列出的文件。

## 唯一输出

只写 `work/image_optimization.json`，不得写其他文件。输出必须是 UTF-8 JSON，结构严格如下：

```json
{
  "version": 1,
  "segment_indices": [1, 2],
  "global_elements": [
    {
      "id": "PERSON_01",
      "kind": "person",
      "source": "跨段重复出现的原人物可见特征",
      "replacement": "统一的新人物身份和可复用外观特征",
      "segments": [1, 2]
    }
  ],
  "segment_prompts": [
    {
      "segment_index": 1,
      "prompt": "本段真实提交给 Seedream 的完整提示词"
    },
    {
      "segment_index": 2,
      "prompt": "本段真实提交给 Seedream 的完整提示词"
    }
  ]
}
```

- `segment_indices` 必须与请求段号完全一致。
- `segment_prompts` 必须覆盖全部段并按段号升序排列；每段提示词非空、恰好两句，Unicode 字符数不超过 140。
- 短视频的 `segment_indices` 是 `[0]`，`global_elements` 必须是空数组。
- 除规定字段外不得增加字段；不得用 Markdown 代码围栏包裹 JSON。

## 执行顺序

四步必须按顺序完成，不得交错：

1. 全项目识别重复实体与高风险关系。
2. 对每个跨段相关组件只冻结一次 `person` 或 `scene` 策略。
3. 完成全部 `global_elements`。
4. 最后派生全部 `segment_prompts`。

任何段级选择不得覆盖项目策略。冻结策略不得等权折中：一级是最终视频连续性与现实合理性，任何扭曲、元素突变、物理或接触关系异常均一票否决；仅在通过一级后评价二级，人物或背景替换仅用于去重。

## 单一目标选择

1. 落实已冻结的跨段策略；没有跨段策略时，每段只选择一个主要编辑目标，严格二选一：`人物外观`或`背景`。
2. `人物外观`指一个人物的新面孔；可连同同色、同用途、同风格但不同款的服装一起设计，并仍视为同一个人物替换目标。新人物保持可见的性别呈现、相近年龄和整体气质，长相略有不同；不推断身份或具体族裔。
3. 多帧中人物脸部和服装足够可见、能够建立稳定同一性时，优先选择人物外观；否则选择背景。选择人物外观时不得修改背景；选择背景时不得修改人物或服装。
4. 背景替换保持场景类别与功能，只设计同类型但不重复的真实背景；不得借背景替换改动前景主体、核心物体或关系。
5. 画质、功能道具、玩具、商品、宠物不得作为差异化目标。不得在同一段同时替换人物外观和背景，也不得增加第二个替换目标。
6. 没有人物时不得新增人物；不可见的信息不得推断或虚构。

## 不可编辑内容

- 核心商品、功能道具、玩具、手部，以及人与物/物与物的握持、接触、插入、对齐、连接、遮挡、前后顺序、数量、结构、方向，全部不可编辑；不得同类改款。
- 保持目标帧自身的画幅、裁切、机位、镜头、透视、景别、构图、光线、焦点、景深、人物与动物数量、姿态、动作、视线，以及非目标元素的位置、比例和可见部分。
- 提示词只点名目标帧中最容易误改的剧情核心物体和关系，不复述全部构图或叙事，不描述视频过程、运镜、转场、台词或音频。
- 禁止恢复或新增字幕、文字、Logo、水印、贴纸、界面元素、品牌标识或乱码。

## 跨段一致性

1. 所有真正被替换且跨段重复的元素都必须进入 `global_elements`，不得遗漏；只能使用 `PERSON`、`OUTFIT`、`SCENE`，PROP、PRODUCT、SUBJECT 不得建立新映射。只出现于一段或仅被保持的元素不进入。
2. 人物使用 `PERSON/person`，人物目标中一并替换的服装使用 `OUTFIT/outfit`，背景使用 `SCENE/scene`。同类 ID 从 `01` 连续编号，整个数组按完整 `id` 字典序输出。
3. `source` 只写识别原目标所需的稳定可见特征；`replacement` 只写可直接复用的新身份或新设计，不写构图、动作、光线、位置或关系。
4. `segments` 只列实际执行该替换的段号，升序、去重且至少包含两段。相同替换描述必须跨段逐字复用。
5. 同一 `chain_id` 的 `continue` 段优先视为连续画面；`hard_cut` 不自动代表人物或场景变化，仍以可见证据判断。

## 每段 Seedream 提示词

每段全部关键帧共享一份可直接提交给 Seedream 的提示词。提示词恰好两句，Unicode 字符数不超过 140：第一句只写唯一替换目标及冻结设计；第二句只写本段最危险的一项关系和其余不变。禁止画质增强、道具替换、构图叙事复述，也不得包含 Markdown、解释或分析。生成前计数，超长必须重写，不能截断。
