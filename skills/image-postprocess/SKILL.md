# image-postprocess

## 目标

关键帧可能在进入视频生成前接受 Seedream 二次编辑。主要目标是在保持每帧镜头内容的前提下，对人物、服装及具体场景做受控差异化，并让重复元素在段内保持同一套新设计；画质改善只是次要目标。

本 Skill 只生成提示词，不编辑图片、不调用 Seedream。生成提示词不代表二次编辑一定执行、成功或被视频生成采用。

## 输入与输出

只允许读取：

- `work/keyframes/01.png、02.png …`：同一片段的全部冻结关键帧。
- `work/request.json`：`edit_mode` 只能是 `independent_parallel` 或 `anchor_consistency`。
- 多段项目还包含 `work/continuity.json`：后端已经筛选出的本段全局元素映射；不得读取其他分段图片。

固定输出 `work/image_optimization_prompt.txt`：

- 本段所有关键帧共享一份可直接提交给 Seedream 的提示词。
- 简体中文 UTF-8 纯文本，非空且不超过 32KB；不包含 Markdown、解释或分析。
- 不得读取视频、视频生成提示词、台词、音频、其他片段或工作目录外文件。

## 核心规则

1. 检查全部关键帧，只依据可见信息建立“原元素 → 新元素”的段内转换方案。
2. 存在 `continuity.json` 时，文件中的全局 ID、原元素识别和新设计是跨段冻结约束：本段出现相应原元素时必须逐字采用其 `replacement`，不得重新设计；映射外且只在本段出现的元素才可建立段内方案。
3. 提示词只描述可跨帧复用的元素身份和外观，不得包含“原镜头语义参考”，不复述任何单帧画面，不写视频叙事、动作过程、运镜、转场、台词或音频。
4. 每次编辑都以第一张输入图片作为目标帧。目标帧自身的画幅、裁切、机位、镜头、透视、景别、构图、光线、焦点、景深、人物数量、姿态、动作、视线，以及各元素的位置、比例、遮挡和接触关系必须保持不变。
5. 其他输入图片只是元素锚点：仅用于识别重复出现的人物、服装、核心主体、道具和场景，并复用它们已经确定的新身份或新设计。锚点不提供内容、构图、动作、机位、景别、光线或位置参考。
6. 仅当目标帧本身存在某元素时，才应用对应转换；不得从锚点向目标帧新增人物、商品、道具、背景物体或任何只在锚点中出现的内容。
7. 不得写某一帧特有的空间描述或把它升级为全段保持项，例如“保持第一张图片的近距离俯拍机位”“手持玩具位于前景”“猫位于后方”。

## 差异化要求

- 人物：面部信息足够可见时，换成同性别呈现、相近年龄、肤色、族裔外观风格和整体气质，但长相略有不同的自然新面孔；只写可见外观，不推断或命名具体族裔、身份或个人。
- 非人主体：保持物种、体型、毛色或主要外观风格，换成外观略有不同但自然可信的另一个个体；不得改变动作和位置。
- 服装：保持主要颜色、用途和整体风格，改变具体款式，如版型、领口、袖型、剪裁或面料纹理；不得改变姿态和覆盖关系。
- 场景：保持场景类别、功能、目标帧自身布局和光线，替换为同类型但不重复的真实场景；可改变墙地材质、家具设施造型、植被或非核心背景细节。
- 非核心道具：保持用途、主要颜色、尺寸及目标帧中的位置和接触关系，换成同类型的不同款式。
- 核心商品：保持类别、数量、结构、主要颜色、功能部件和真实商品信息，不得增删或改造商品部件。
- 质量：完成内容差异化后，才可适度改善曝光、白平衡、噪点、压缩痕迹和自然清晰度；保持真实摄影质感。

同一原人物、服装、道具或场景在全部关键帧中必须一一对应到同一个新人物或同一套新设计，不得逐帧随机变化。某项不可见时不虚构；没有人物时不得新增人物。

禁止恢复或新增字幕、文字、Logo、水印、贴纸、界面元素、品牌标识或乱码。

## 输出步骤

1. 识别核心商品，以及跨帧重复的人物、服装、道具和场景。
2. 先采用 `continuity.json` 中与本段有关的冻结映射，再为其余可差异化元素确定段内转换方案。
3. 写清目标帧与元素锚点的权限边界。
4. 依次写差异化目标、元素转换方案、目标帧保持项和禁止事项。
5. 删除所有单帧叙事、空间布局复述和空泛画质描述后，写入唯一输出文件。

提示词必须逐字以下段开头，使目标图与锚点图的权限边界对用户可见：

> 为降低素材重复度，对本次第一张输入图片进行受控内容级二次编辑。第一张输入是唯一目标帧；其他输入仅作为重复元素的新身份与新设计锚点，绝不作为构图或画面内容参考。每次均保持目标帧自身的机位、镜头、光线、构图、动作和元素位置。
