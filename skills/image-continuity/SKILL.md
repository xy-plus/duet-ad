# image-continuity

## 目标

为多段视频建立一次性、可冻结的全局元素映射。只定义跨段重复元素的身份和替换方案，不生成 Seedream 编辑提示词，不编辑图片。

## 输入与输出

只允许读取：

- `work/segments/<段号>/keyframes/01.png、02.png …`：全部分段的冻结关键帧。
- `work/request.json`：各段的 `index`、`chain_id` 和 `join_mode`。

固定输出 `work/continuity.json`，不得写其他文件。输出必须是 UTF-8 JSON：

```json
{
  "version": 1,
  "segment_indices": [1, 2],
  "elements": [
    {
      "id": "PERSON_01",
      "kind": "person",
      "source": "跨段重复出现的原人物可见特征",
      "replacement": "统一的新人物身份与可复用外观特征",
      "segments": [1, 2]
    }
  ]
}
```

## 规则

1. `segment_indices` 必须与请求段号完全一致且升序排列。
2. 识别跨段重复出现的人物、非人主体、服装、场景、道具和核心商品；同一原元素只建立一个全局 ID。
3. ID 前缀和 `kind` 必须对应：人类使用 `PERSON/person`，宠物、动物等非人主体使用 `SUBJECT/subject`，其余使用 `OUTFIT/outfit`、`SCENE/scene`、`PROP/prop`、`PRODUCT/product`；不得把动物归为 `PERSON`。同类 ID 从 `01` 连续编号，所有元素按 ID 升序输出。
4. `source` 只写足以识别原元素的稳定可见特征；`replacement` 只写统一的新身份或新设计。不得描述任何分段或单帧的构图、机位、景别、动作、光线、前后景及元素位置。
5. `segments` 只列实际出现该元素的段号，升序且不得重复。某元素只出现在一段时不必进入全局映射。
6. 同一 `chain_id` 的 `continue` 段优先视为连续画面；`hard_cut` 不自动等于新人物或新商品，也不自动等于同一场景，必须以可见证据判断。
7. 人物替换保持同性别呈现、相近年龄、肤色、族裔外观风格和整体气质，但使用长相略有不同的新面孔。
8. 非人主体保持物种、体型、毛色或主要外观风格，统一换成外观略有不同但自然可信的另一个个体。
9. 服装保持主要颜色、用途和整体风格，统一换成另一具体款式。
10. 同一场景保持类别和功能，统一换成同类型但不重复的真实环境设计；不同原场景不得被错误合并。
11. 非核心道具可映射为同类型不同款式；核心商品只建立跨段身份，不改变类别、结构、颜色、功能部件和真实商品信息。
12. 只依据全部关键帧中的可见证据，不推断姓名、身份、具体族裔或不可见细节。

若没有任何跨段重复元素，输出相同 `version` 和 `segment_indices`，并令 `elements` 为空数组。
